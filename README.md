# Neuroslop Bot

Telegram-бот для канала с мемами и мини-сериалами. Один бот делает две вещи:

1. **Предложка** — подписчики присылают видео/фото, админ модерирует в приватном
   чате и публикует в канал одним нажатием.
2. **Навигация** — подборки двух типов: упорядоченные мини-сериалы (серии с
   номерами) и папки. Плюс случайный пост.

## Что умеет

- Приём заявок: одно видео или фото за раз, проверка подписки, лимит в сутки.
- Два входа для заявок: личка с ботом («Предложить видео») и админ-чат
  (просто загрузить видео/фото — бот сам создаст заявку).
- Модерация в приватном админ-чате: «Опубликовать» / «В подборку» / «Отклонить».
- «📥 Заявки» и команда `/queue`: все неразобранные заявки, карточку можно
  вызвать заново, даже если проскроллил чат.
- Комментарий автора из подписи к файлу виден в карточке (в канал не попадает).
- Дубликаты: если такой файл уже публиковался или уже висит в очереди, в карточке
  будет предупреждение со ссылкой на пост.
- Баны с разбаном: `🚫 Заблокировать` в карточке, раздел «🚫 Баны» в админке.
  Бан блокирует только новые заявки.
- «🗓 Отложено» и `/scheduled`: список отложенных публикаций; можно
  опубликовать сейчас, изменить время или отменить (заявка вернётся в очередь,
  автор получит уведомление).
- Управление постами: в админской карточке подборки — список серий; у поста можно
  изменить подпись, скрыть/вернуть из подборок или удалить из канала и базы.
- Старые посты: перешли пост из канала боту (в личку или в админ-группу) — бот
  предложит добавить его в подборку. Хештег/номер/кнопки на самом старом посте
  добавить нельзя (его публиковал не бот), но в подборках и «Случайном» он
  появится.
- Публикация от имени канала с подписью, хештегом подборки и номером серии.
- Кнопки под каждым постом: «Предложить видео», «Подборки», опционально «Случайный пост».
- У серий — кнопки «Предыдущая» / «Следующая».
- Подборки: список, просмотр, отправка всех серий альбомом (до 10) или ссылками.
- «Мои заявки» — подписчик видит статусы своих заявок.
- Отложенная публикация: кнопки `+15 мин` … `+4 часа`, «Сегодня 19:00»,
  «Завтра 10:00» или ручной ввод (`через 2 часа`, `18:30`, `25.10 18:00`).
- Настройки прямо в боте: лимиты, размеры, подписка, тексты, кнопка «Случайный».
- Уведомления авторам об опубликовании/отклонении.
- Статистика и топ авторов.

## Требования

- Сервер с Docker и Docker Compose.
- Python не нужен: всё внутри контейнера.
- Исходящий доступ в интернет (long polling, входящие порты не нужны).

## Подготовка в Telegram

1. **Бот.** Создай у [@BotFather](https://t.me/BotFather) (`/newbot`), сохрани токен.
2. **Канал.** Добавь бота админом с правом «Публикация сообщений».
3. **Админ-чат.** Приватная **группа** (рекомендуется) или канал; добавь бота
   админом. Туда падают заявки с кнопками. Если это группа, весь диалог
   модерации (подпись, подборка, время) идёт прямо в ней. Если канал — диалог
   уйдёт в личку админу, потому что в канале нельзя ответить текстом.
4. **ID.** Числовые ID канала и чата можно получить, переслав сообщение боту
   `@userinfobot` / `@getidsbot`, либо через API. Свой Telegram ID — там же.
5. Включи в BotFather `/setprivacy` → Disable, только если бот должен читать
   все сообщения в группе (для модерации это не требуется).

> Топики («Темы») необязательны. Если включены, укажи `ADMIN_TOPIC_ID`.

## Установка

```bash
git clone <repo-url> neuroslop-bot
cd neuroslop-bot
./deploy/install.sh
```

Скрипт спросит токен, ID канала, ID админ-чата, ID админов и создаст `.env`.
Повторный запуск `install.sh` безопасен — он пересоберёт и перезапустит бота.

Можно заранее скопировать `.env.example` в `.env` и заполнить вручную:

```bash
cp .env.example .env
chmod 600 .env
$EDITOR .env
./deploy/install.sh
```

## Обновление

```bash
./deploy/update.sh
```

## Бэкап и восстановление

```bash
./deploy/backup.sh                 # в backups/neuroslop-<дата>.tar.gz, хранит 14 дней
./deploy/restore.sh backups/neuroslop-2026-10-23-120000.tar.gz
```

База — SQLite в `./data/neuroslop.sqlite3`. Медиа не хранится: только `file_id`
и номера сообщений, сами файлы лежат на серверах Telegram.

Для ежедневного бэкапа добавь cron:

```
0 4 * * * /path/to/neuroslop-bot/deploy/backup.sh >> /var/log/neuroslop-backup.log 2>&1
```

## Как пользоваться

**Подписчик** открывает бота (`/start`) и видит меню. Заявка = один файл.
Статусы — «Мои заявки». Подборки и случайный пост — из меню или по кнопкам
под постами канала.

**Админ** открывает бота в личке и жмёт «Админка» (или `/admin`).

**Модерация.** Заявка приходит в админ-чат с кнопками. Дальше диалог идёт там же
(в группе) либо в личке, если админ-чат — канал:

- «Опубликовать» → подпись → сейчас или отложить;
- «В подборку» → выбрать/создать подборку → номер серии → подпись → время;
- «Отклонить» → причина (или `/skip`).

Подпись опциональна: `/skip`. Хештег и номер серии добавляются автоматически.

## Настройки (в боте)

| Настройка | По умолчанию |
|---|---|
| Лимит заявок в сутки | 3 (0 = без лимита) |
| Макс. размер видео, МБ | 50 |
| Макс. длительность видео, сек | 300 |
| Макс. размер фото, МБ | 10 |
| Только подписчики | вкл |
| Кнопка «Случайный» под постами | выкл |
| Текст «Правила» | задан |

## Структура

```
app/
  main.py            точка входа, polling
  config.py          переменные окружения
  db.py              SQLite, миграции, настройки
  sessions.py        состояние диалогов модерации
  scheduler.py       отложенные публикации
  handlers/
    user.py          подписчик: заявки, подборки, случайный пост
    moderation.py    карточки заявок и диалог модерации
    admin.py         админка: подборки, настройки, статистика
  services/
    publishing.py    публикация, подписи, клавиатуры
    collections.py   создание подборок, нумерация серий
migrations/          SQL-миграции (применяются при старте)
deploy/              install/update/backup/restore
```

## Ограничения MVP

- Одна заявка = один файл, альбомы не поддерживаются.
- «Кружки» (video note) не принимаются — только обычное видео, фото или файл.
- Старые посты добавляются в подборки только пересылкой из канала; альбомы и
  форварды из других каналов не поддерживаются.
- Один канал.
- Нет веб-админки: всё управление в боте.
- Переключатель «Случайный под постами» влияет на новые посты; у старых
  клавиатура не перестраивается (кнопку можно добавить только при публикации).
- Удалённые из канала посты не отслеживаются автоматически: ссылка станет
  битой. Удалять/скрывать нужно через карточку поста в админке.
- Номера серий не переиспользуются: после удаления серии следующая получит
  следующий номер, в нумерации останется пропуск.

## Смена username бота

Если меняешь `@username` в BotFather, старые кнопки под постами сломаются.
Порядок:

1. BotFather → `/setusername` → новый username (проверь, что свободен).
2. При желании `/setname` → отображаемое имя.
3. Перезапусти контейнер: `docker compose restart`.
4. В боте: «⚙️ Админка → 🔧 Сервис → 🔁 Пересобрать кнопки».
5. Обнови ссылку на бота в описании канала.

Кнопки у постов, опубликованных ботом, обновятся. У пересланных старых постов
кнопок нет — их менять нечего.

## Безопасность

- В репозитории нет секретов: токен и ID — только в `.env` (в `.gitignore`).
- Все изменяющие действия доступны только ID из `ADMIN_USER_IDS`.
- Если токен утёк — перевыпусти его в BotFather (`/revoke`) и обнови `.env`.

## Troubleshooting

**Бот не публикует: «chat not found».** Бот не админ канала или неверный
`CHANNEL_ID`. Проверь: «Админка → Сервис».

**Заявки не приходят.** Неверный `ADMIN_GROUP_ID` или бот не админ там.

**«Открой бота в личке и нажми /start».** Админ ещё не запускал бота в личке —
бот не может написать первым.

**Бот молчит.** `docker compose logs -f`, проверь `BOT_TOKEN`.

**Не приходит проверка подписки.** Бот должен быть админом канала; иначе
проверка пропускается (fail-open).

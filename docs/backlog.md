# Бэклог и багрепорты

Формат записи: дата, короткое описание, статус.

## Баги

Пока открытых нет.

## Требует согласования

| Проблема | Почему не исправлено автоматически |
|---|---|
| Проверка подписки fail-open при ошибке Telegram API | Исправление меняет пользовательское поведение (в спорной ситуации подписчик не сможет отправить заявку). Нужно решение владельца. |
| Нет healthcheck у контейнера | Требует отдельного механизма проверки живости; не влияет на текущую работу. |

## Идеи и доработки

| Идея | Статус |
|---|---|
| «🔢 Номер серии» в карточке поста (правка эпизода у существующего поста) | запланировано |
| Объединить «✅ Опубликовать» и «📁 В подборку»: после публикации спрашивать «В подборку / Без подборки», а тип подборки определяет, нужен ли номер серии | обсудить |
| Оформление подписи: первая строка текста админа — ручной заголовок жирным; ссылка источника — курсивом; хештег и `S1E5` без изменений. Сезоны в заголовке не генерировать (можно вписать руками). Старые посты не переоформлять; должна оставаться возможность править подпись через админку (для постов, опубликованных ботом) | запланировано |
| Переделать «Мои заявки»: главный экран — 10 последних, время отложки, опубликованные строки-ссылки; одна кнопка «Детали» → список заявок по 10 с листалкой → карточка (статус, тип, дата отправки, подборка/серия, время публикации, заголовок, комментарий автора, причина отказа, кнопка «Открыть пост» при наличии). Заявки со статусом `deleted` не показывать нигде. Ручное удаление поста из канала не отслеживается — ссылка может стать битой | запланировано |
| Переименовать репозиторий и проект в `content-shelter` / «Content Shelter»: `gh repo rename`, README, описание, remote. Внутренние имена (container_name, БД, volume) не трогать | запланировано |
| Переименование канала (обсуждали «Слоп-приют») | на паузе |
| Кружки (video note) | отложено |
| Автоочистка старых отклонённых заявок | отложено |
| Смена username бота | невозможно (Telegram не позволяет менять username бота) |
| Веб-админка | не планируется (всё в боте) |
| Альбомы в заявках | не планируется в MVP |

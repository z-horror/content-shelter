# Нейрослоп — дизайн бота

Канал с нейрослоп-мемами и мини-сериалами. Один бот выполняет две роли:
приём заявок от подписчиков и навигация по подборкам.

## 1. Цели MVP

- Подписчик присылает боту **один файл** (видео или фото) через кнопку «Предложить».
- Админ получает заявку в приватной админ-группе и решает: опубликовать,
  опубликовать в подборку, отклонить.
- Бот публикует пост в канал от своего имени, с подписью, хештегами и кнопками.
- Под каждым постом кнопки «Предложить видео» и «Подборки».
- Подборки двух типов: упорядоченные (мини-сериалы, серии с номерами)
  и неупорядоченные (папки, порядок = порядок публикации).
- Бот отдаёт список серий подборки ссылками на сообщения канала.
- «Случайный пост» из опубликованного.
- Уведомление автору об опубликовании/отклонении.
- Лимиты и размеры настраиваются из админ-меню в боте.

## 2. Не входит в MVP

- Альбомы (несколько файлов в одной заявке).
- Веб-админка.
- Несколько каналов.
- Автопостинг по расписанию (отложенная публикация конкретного поста — входит).
- Рейтинг/лидерборд авторов в интерфейсе (счётчики в БД есть).
- Скачивание по ссылкам из Instagram.

## 3. Роли

| Роль | Где | Права |
|---|---|---|
| Подписчик | личка с ботом | предложить файл, смотреть подборки, случайный пост |
| Админ | админ-группа + личка | модерация, подборки, настройки, статистика |
| Бот | канал | постинг, редактирование своих постов |

Админы задаются списком Telegram ID в `.env` (`ADMIN_USER_IDS`).

## 4. Модель данных (SQLite)

```sql
-- применяемые миграции
PRAGMA user_version;

settings (
  key   TEXT PRIMARY KEY,
  value TEXT NOT NULL
)
-- submit_daily_limit, video_max_mb, video_max_seconds,
-- photo_max_mb, require_subscription, moderation_topic_id, ...

users (
  id                INTEGER PRIMARY KEY,      -- telegram user id
  username          TEXT,
  first_name        TEXT,
  submissions_total INTEGER NOT NULL DEFAULT 0,
  approved_total    INTEGER NOT NULL DEFAULT 0,
  last_random_post  INTEGER,                  -- антиповтор
  created_at        TEXT NOT NULL
)

collections (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  name        TEXT NOT NULL,
  slug        TEXT NOT NULL UNIQUE,           -- для #хештега
  is_ordered  INTEGER NOT NULL DEFAULT 0,     -- 1 = сериал
  season      INTEGER NOT NULL DEFAULT 1,
  position    INTEGER NOT NULL DEFAULT 0,     -- порядок в меню
  created_at  TEXT NOT NULL
)

submissions (
  id               INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id          INTEGER NOT NULL REFERENCES users(id),
  source_chat_id   INTEGER NOT NULL,          -- чат с ботом
  source_message_id INTEGER NOT NULL,
  media_type       TEXT NOT NULL,             -- video | photo | document
  file_id          TEXT,
  status           TEXT NOT NULL DEFAULT 'pending', -- pending|approved|rejected
  admin_chat_id    INTEGER,                   -- где лежит карточка заявки
  admin_message_id INTEGER,
  created_at       TEXT NOT NULL,
  reviewed_at      TEXT,
  reviewer_id      INTEGER
)

posts (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  channel_id    INTEGER NOT NULL,
  message_id    INTEGER NOT NULL,
  submission_id INTEGER REFERENCES submissions(id),
  collection_id INTEGER REFERENCES collections(id),
  season        INTEGER,
  episode       INTEGER,
  media_type    TEXT NOT NULL,
  caption       TEXT,
  author_id     INTEGER REFERENCES users(id),
  published_at  TEXT NOT NULL,
  is_deleted    INTEGER NOT NULL DEFAULT 0,
  UNIQUE (channel_id, message_id)
)

CREATE UNIQUE INDEX idx_episode
  ON posts (collection_id, season, episode)
  WHERE episode IS NOT NULL;

CREATE INDEX idx_posts_collection ON posts (collection_id, season, episode, id);
```

Настройки — в `settings`, а не в коде: админ меняет их из бота.
Секреты (токен, ID канала и группы) — только в `.env`.

## 5. Потоки

### 5.1 Заявка

1. Подписчик: `/start` → «📤 Предложить видео».
2. Бот проверяет подписку (`getChatMember` в канале), если включено.
3. Бот проверяет лимит заявок в сутки (`submit_daily_limit`).
4. Бот ждёт **одно** сообщение: видео, фото или документ с видео/фото.
5. Валидация: тип, размер (`video_max_mb` / `photo_max_mb`),
   длительность видео (`video_max_seconds`), не альбом.
6. Бот копирует медиа в админ-группу (`copyMessage`) с подписью-карточкой:
   `Заявка #42 · @username · 12 МБ · 0:34` и кнопками:
   `✅ Опубликовать` · `📁 В подборку` · `❌ Отклонить`.
7. Заявка пишется в `submissions` со статусом `pending`,
   `admin_message_id` сохраняется для последующего редактирования карточки.

Копирование, а не пересылка: в канале не появляется «переслано от».

Дополнительный вход: админ может загрузить видео/фото прямо в админ-чат —
бот создаёт такую же заявку и отвечает карточкой. Источник публикации в обоих
случаях — исходное сообщение (`source_chat_id` / `source_message_id`), а не
карточка.

### 5.2 Модерация

Кнопки — `callback_data` в админ-группе, доступны только ID из `ADMIN_USER_IDS`.

**✅ Опубликовать**
1. Бот спрашивает подпись: «Отправь текст подписи или /skip».
2. Публикация: `copyMessage` в канал с подписью + клавиатура.
3. `submissions.status = approved`, создаётся запись в `posts`,
   инкремент `users.approved_total`.
4. Автору в личку: «Твоё видео опубликовано: <ссылка>».
5. Карточка в админ-группе редактируется: статус + ссылка на пост.

**📁 В подборку**
1. Бот показывает список подборок + «➕ Создать новую».
2. Если подборка упорядоченная: предлагает следующий номер
   (`max(episode)+1`, сезон из подборки), кнопки `✅ Ок` / `✏️ Изменить`.
3. Дальше как «Опубликовать», но с `collection_id`, `season`, `episode`,
   в подпись добавляется хештег и, для упорядоченной, номер серии.

**❌ Отклонить**
1. Бот спрашивает причину (опционально, /skip).
2. `status = rejected`, карточка обновляется.
3. Автору: «Заявка отклонена» (+ причина, если указана).

Отклонённые заявки остаются в БД (статистика, антиспам-история).

### 5.3 Публикация в канал

Единый формат подписи:

```
<текст админа>

#slug               # для неупорядоченной подборки
#slug #s1e3         # для упорядоченной
```

Клавиатура под каждым постом:

```
[ 📤 Предложить видео ] [ 📚 Подборки ]
[ ⬅️ Предыдущая ] [ Следующая ➡️ ]        # только у серий
```

Кнопки — URL-кнопки на диплинки бота:
`t.me/hahinsta_bot?start=submit` и `?start=collections`.

Почему URL, а не callback: callback-кнопка в канале может только показать
всплывашку; чтобы ответить в личку, пользователь уже должен был открывать
бота. URL-диплинк открывает бота сразу с нужным экраном.

Prev/next — тоже URL на `t.me/канал/<id>` соседних серий.
Если соседа нет — кнопка не показывается.

### 5.4 Подборки

`/start` → «📚 Подборки» (или диплинк `?start=collections`):

- список подборок с количеством постов;
- карточка подборки:
  - упорядоченная: `S1E1 — 1:42` … ссылками на сообщения;
  - неупорядоченная: список ссылок по порядку публикации;
  - кнопка «▶️ Прислать все» при ≤ 10 постах (альбом);
  - при > 10 — пагинация по 10 (текстовые ссылки, не альбом).

Ссылки: публичный канал — `t.me/<username>/<message_id>`;
приватный — `t.me/c/<channel_id без -100>/<message_id>`.

### 5.5 Случайный пост

Кнопка в меню бота. Бот выбирает случайный `posts` (`is_deleted = 0`),
исключая `users.last_random_post`, отправляет копию поста с кнопкой
«📚 Подборки» и обновляет `last_random_post`.

## 6. Экраны бота (личка)

```
/start
├── 📤 Предложить видео
├── 📚 Подборки
├── 🎲 Случайный пост
└── ℹ️ Правила            # текст настраивается
```

Админ в личке:

```
/admin
├── 📊 Статистика           # заявок, одобрено, отклонено, топ авторов
├── 📁 Подборки             # создать/переименовать/тип/порядок/удалить
├── ⚙️ Настройки            # лимиты, размеры, подписка, тексты
└── 🔧 Сервис               # проверка канала/группы, переотправка поста
```

## 7. Админ-чат

- Приватный канал или группа, бот — админ.
- Топики не используются. Если позже понадобятся, карточки можно направить
  в топик `ADMIN_TOPIC_ID` — поле в конфиге уже есть.
- Вся модерация — inline-кнопками, без команд.
- Диалоги модерации (подпись, подборка, время) идут в личку админу, состояние
  хранится в таблице `admin_sessions` (переживает рестарт бота).

## 9. Технические решения

- **Python 3.12 + aiogram 3**, long polling (без портов, домена, TLS).
- **SQLite** (WAL), один файл в docker-volume. Миграции — `migrations/*.sql`
  + `PRAGMA user_version`, применяются при старте.
- **Docker Compose**, один сервис, `restart: unless-stopped`,
  volume `./data:/data`, логи с ротацией.
- Хранение медиа: **не храним файлы**. Только `file_id` и `message_id`.
  Медиа уже лежит на серверах Telegram.
- `copyMessage` вместо скачивания и перезаливки: работает с любым размером,
  не тратит трафик и диск.
- Все изменяющие действия админа — только по ID из whitelist.

## 10. Крайние случаи

| Случай | Поведение |
|---|---|
| Пост удалён из канала вручную | Бот не получает событие удаления. Ссылка в подборке станет битой. В админ-меню — «скрыть пост из подборки». Восстановление — только перепост. |
| Бот удалён из канала/группы | При старте и раз в N минут бот проверяет `getChat`/`getChatMember`; при ошибке пишет админам в личку. |
| Пользователь не подписан | Отказ с кнопкой «Подписаться» (ссылка на канал). |
| Альбом | MVP: «пришлите один файл». |
| Два админа жмут кнопку одновременно | Статус заявки проверяется перед действием; повторная публикация блокируется. |
| Telegram API недоступен | Ретраи с backoff, ошибка в лог, заявка не теряется. |

## 11. Поставка

```
neuroslop-bot/
├── app/                 # код бота
├── migrations/          # SQL-миграции
├── deploy/
│   ├── install.sh       # идемпотентная установка
│   ├── update.sh        # git pull + rebuild + restart
│   ├── backup.sh        # sqlite .backup + tar data/
│   └── restore.sh
├── docs/design.md
├── .env.example
├── .gitignore
├── Dockerfile
├── docker-compose.yml
└── README.md
```

`install.sh`: проверка docker/compose → создание `.env` из шаблона
(интерактивно или из готового файла) → `docker compose up -d --build` →
ожидание `getMe` → вывод статуса. Повторный запуск = обновление.

`backup.sh` в cron ежедневно; `restore.sh` — восстановление из архива.

## 12. Принятые решения

1. Топики не используем.
2. «🎲 Случайный пост» — в меню бота; третья кнопка под постами включается
   настройкой `random_button_under_posts`.
3. «📋 Мои заявки» — в MVP.
4. Отложенная публикация — в MVP.

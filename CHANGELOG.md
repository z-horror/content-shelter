# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Версии не тегируем, ориентир — дата.

## [Unreleased]

### Added
- Заявки по ссылкам YouTube/Instagram: скачивание `yt-dlp`, ffmpeg, лимиты
  50 МБ / 10 минут, 2 параллельные загрузки, временная папка с очисткой.
- Метаданные источника (`source_url`, `source_meta`) и заголовок как подпись
  при `/skip` только для ссылочных заявок.
- Настройка «Загрузка по ссылкам» в админке.
- Единый сценарий «Опубликовать → В подборку / Без подборки».
- Новый экран «Мои заявки»: последние 10, время отложки, кликабельные
  опубликованные строки, «Детали» с пагинацией и карточкой.
- Экран подборок: 📺 сериалы и 📁 папки, дата публикации, автор клипа,
  заголовки для папок, корректные счётчики.
- Оформление подписи: первая строка жирным, ссылки курсивом.
- Админские подборки: 📺/📁 и сериалы сверху; список постов с датой и автором,
  карточка поста с автором.
- Дата и время (`23.10 15:42`) во всех списках: заявки, детали, подборки,
  админские посты, «Заявки» и «Отложено».
- Авторы в подборках: админ видит всех; пользователь — «вы» у своих,
  «скрыт» у чужих, «из канала» у постов без автора.
- Кнопка «⬅️ К подборке» после «▶️ Прислать все».
- Репозиторий и проект переименованы в `content-shelter` / «Content Shelter».
  Внутренние имена (`container_name`, БД, volume) не менялись.
- Атомарные миграции: SQL и `PRAGMA user_version` в одной транзакции.
- Хелпер транзакций SQLite; связанные записи публикации, очереди, бана,
  отмены и удаления поста меняются атомарно.
- Резерв заявки на публикацию (`submissions.publishing_at`) — защита от
  одновременной и повторной публикации.
- Классификация ошибок Telegram: определённые (резерв снимается) и
  неопределённые (автоповтор запрещён).
- Безопасный повтор только при `TelegramRetryAfter`.
- Восстановление очереди после рестарта: `done` при наличии поста, иначе
  `unknown` без автоповтора; при наличии поста заявка сверяется и переводится
  в `approved`.
- Проверка целостности бэкапа и архива восстановления, обязательные таблицы,
  права `600`.
- `docs/operations.md` — обновление, бэкапы, восстановление, диагностика
  незавершённых публикаций.
- Тесты (19) на временных SQLite-базах и фиктивном Telegram-боте.

### Changed
- `deploy/restore.sh` сохраняет текущую базу в `data/pre-restore-*` и
  откатывается автоматически при неудачном запуске.
- `deploy/install.sh` всегда выставляет права `600` на существующий `.env`.
- Проект переведён на одну рабочую ветку `main`.

### Fixed
- Возможные дубли при конкурентной публикации и повторном нажатии.
- Повторная публикация после аварийного завершения.
- Частичные состояния при сбоях между записями в БД.
- Неатомарные миграции.
- Возможный дубль при откате очереди после рестарта.

## 2026-10-23

### Added
- Предложка: приём одного видео/фото, проверка подписки, лимит заявок в сутки.
- Модерация в приватной группе: «Опубликовать» / «В подборку» / «Отклонить».
- Публикация в канал с подписью, хештегом подборки и номером серии.
- Кнопки под постами: «Предложить видео», «Подборки», опционально «Случайный пост».
- Подборки двух типов: сериалы с нумерацией и папки.
- «Подборки» в боте: список, просмотр, отправка альбомом/ссылками.
- «Случайный пост».
- «Мои заявки» со статусами.
- Админка: заявки, отложенные, статистика, подборки, настройки, сервис.
- «📥 Заявки» и `/queue` — неразобранные заявки с повторным вызовом карточки.
- «🗓 Отложено» и `/scheduled` — список отложенных, перенос/отмена/публикация сейчас.
- Быстрый выбор времени: +15м…+4ч, «Сегодня 19:00», «Завтра 10:00», ручной ввод.
- Ручной парсер времени: `через 2 часа`, `завтра 10`, `25.10 18:00`.
- Комментарий автора в карточке заявки.
- Уведомления авторам: публикация, отклонение, перенос, отмена, бан/разбан.
- Дубликаты по `file_unique_id` со ссылкой на существующий пост.
- Баны с причиной, разделом «🚫 Баны» и разбаном.
- Управление постами: список серий в подборке (пагинация), правка подписи,
  скрытие/возврат, удаление из канала и базы.
- Номера серий не переиспользуются (счётчик `collections.last_episode`).
- Пересылка старых постов из канала боту → добавление в подборку.
- «🔁 Пересобрать кнопки» в сервисе — пересборка клавиатур существующих постов
  под текущие настройки.
- Двухколоночное админ-меню со счётчиками заявок и отложенных.
- Docker-деплой: `install.sh`, `update.sh`, `backup.sh`, `restore.sh`.

### Changed
- «Очередь» переименована в «Заявки».
- Email-подобные ограничения: одна заявка = один файл, альбомы не принимаются.

### Fixed
- `copy_message` возвращает `MessageId`, а не `Message` (падала публикация).
- Публикация брала карточку вместо исходного файла.
- `/skip@bot` в группах не распознавался.
- Дубли серий: пост удаляется из канала при ошибке записи в БД.
- Зависшие задачи планировщика после рестарта.
- Гонки и повторная публикация одной заявки.
